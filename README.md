# Quax
## Hi! I'm Quax, and I'm here to help you with your coding project without getting trapped in the "vibe-coding" hype.

Think back to before the future hit us like a quack-ton of bricks... When you needed boilerplate code to get started on a feature you were developing, you'd have turned to resources like w3schools or HowToGeek. Only after googling, scrolling and trying different links would we find relevant snippets of code that we could copy into our project and build off of.

I've developed an app that makes this method obsolete. 

Need a CSS class definition that will turn a <div> into a modal?
Connect the AI assistant of your choice to Quax, and ask Quax for the code!
This will generate a click-to-copy code snippet card, which will save to a grid alongside all of the other snippets you've requested.

Now you have templates and boilerplate code snippets that you'll reuse across various projects right at your fingertips.

Just launch Quax from your desktop, unload your troubles onto your rubber duck assistant, and profit.
When you need to reuse a concept you used Quax for in the past, filter your collection by programming language, search for the snippet you need,
the click to copy & paste into your IDE.
